# VitaRossa

VitaRossa: Connecting Life in Every Drop.

## Frontend Application

Modern Blood Bank Management & Donor Network Platform built with React, TypeScript, Vite, and Redux Toolkit.

### Tech Stack
- **Framework:** React 18 + TypeScript + Vite
- **State Management:** Redux Toolkit
- **Styling:** Vanilla CSS with custom design tokens
- **PWA Support:** Vite PWA

### Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
